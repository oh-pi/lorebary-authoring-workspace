# Public format updates

## 0.2 — 2026-09-11

- Added 18 blank templates/fragments; 99 are now available across six independent categories.
- Added character PNG payloads, extended personality and structured/detailed root variants, START dialogue and optional appearance layouts.
- Added detailed/freeform persona payloads and optional creator metadata for personas, scenarios, plugins and lorebooks.
- Kept existing plugin logic families and prompt settings variants. Documented prompt header/body consistency checks.
- Added category suffixes to template names and generated-asset naming rules. Existing template names have changed; select their category-suffixed equivalents from each chooser.
- Expanded ignore rules to keep private rescan history out of shared forks.

The reference collection, artwork, private indexes, source filenames, local approval records and review snapshots are excluded. Blank templates have not been independently imported; decoded JSON payloads are not finished PNG files. MIT licensing and the legal notice remain unchanged.
