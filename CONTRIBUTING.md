# Contributing

Please contribute reusable formatting knowledge, blank templates, documentation improvements, or corrections. Keep each category's context and structural variants separate.

Do not commit downloaded reference assets, private generated sets, personal metadata, account IDs, credentials, image payloads, creative examples copied from other people, or private provenance records. A public example elsewhere is not automatically licensed for redistribution here. Describe structural evidence in your own words and use content-free examples where possible.

For a format change, state the category and variant, what is observed versus documented or uncertain, which field types/text markers change, and what validation was performed. Preserve deliberate variants instead of declaring every difference an error. Report import tests only if actually performed. Avoid adding software-framework dependencies for simple authoring tasks.

Keep your working references and generated sets in the ignored local folders. Review the staged diff before submitting. Do not force-add private files. A contribution should be something you have the right to submit; contributions intended for this project are offered under its MIT License unless a different arrangement is explicitly agreed before submission. Retain existing notices. The project does not request ownership of your private creative work.

Read [legal.md](legal.md). This project remains unofficial, and provider/platform policies continue to apply independently of the repository license.
